# Лабораторная работа №2: Многопоточный анализ текстовых данных

Данный проект содержит реализацию многопоточного подсчёта частоты слов в текстовых файлах. В работе исследуются различные подходы к синхронизации и совместному доступу к изменяемым данным с использованием средств пакета `java.util.concurrent`.

## Требования

Для сборки и запуска проекта необходимы следующие инструменты:
- Java 21 (Temurin или аналогичная сборка)
- Apache Maven
- Git

## Структура проекта

- `src/main/java/ru/seva/lab2/` — исходный код генератора данных, интерфейсов, реализаций анализаторов и бенчмарка.
- `results/` — папка с результатами экспериментов (таблицы измерений, графики и аналитические выводы).

## Генерация тестовых данных

Перед началом экспериментов необходимо сгенерировать эталонный набор текстовых файлов. Выполните следующие команды в корневой директории проекта:

```bash
mvn compile
java -cp target/classes ru.seva.lab2.TestDataGenerator generated-data
